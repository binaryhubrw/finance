01 Reading the interface

These cues mean the same thing everywhere they appear.

CueMeaning
Amber bar down the left edge The entry is pending. It has not counted yet.
– Dash instead of a figure Deliberately not a number. Either the entry is not approved, or nothing was entered.
Struck-through description The entry is void. It stays in the book but counts for nothing.
Green figure Money in.
Red figure Money out, or a negative variance.
Underlined description You can click it to edit that entry. Not underlined means you cannot edit it.
Pending Approved The entry's current state. Also Rejected and Void.
Number badge on the Approvals link How many entries are waiting for review, across the whole book.

Why the figures look like that

Every figure is right-aligned and set in a monospace face so digits stack in a column. A column of numbers that does not line up is hard to check, and checking is the job.

02 Sign in

The only screen you can reach without an account.

ControlWhat it does
EmailYour work email address. Not case-sensitive.
PasswordAt least 8 characters.
Sign inSigns you in and opens the Overview — or the page you were trying to reach.

After ten failed attempts for the same email, sign-in is refused for fifteen minutes. Nothing on this screen can create an account or reset a password; an administrator does both.

06 Record entry / Edit entry

Accountant Administrator

The same dialog does both. Opened by Record entry, or by clicking an underlined description in the ledger.

FieldNotes
DateDefaults to today. Future dates are refused by the picker itself.
DirectionTwo buttons — Money in and Money out. Switching them clears the budget line, because the list of lines depends on the direction.
AmountGreater than zero. Two decimal places allowed.
Budget lineOnly lines matching the direction appear: income lines for money in, expense lines for money out. Starts as "Choose a line".
DescriptionRequired, up to 300 characters. This is what the auditor reads first.
Paid to / Received fromThe label follows the direction.
MethodCash, Mobile money, Bank, Other. Defaults to Cash.
ReferenceReceipt number or mobile money transaction ID.
Receipt linkA URL to a photo of the receipt. The system stores the link, not the image.
NoteUp to 500 characters, for anything the auditor should know.
ControlWhat it does
CancelCloses without saving.
Record entry / Save changesSaves. A new entry is created as pending.
Void this entryOnly on an existing entry. Opens a reason box; Void this entry confirms, Keep it backs out. A reason is required.

The dialog tells you what will happen before you commit: a new entry says it waits for an auditor, and an edit says that changing a reviewed entry sends it back to the queue.

Leave the reference and receipt link empty on an expense and the entry is flagged under Exceptions. It still saves — this is a prompt, not a block.

07 Import a sheet

Accountant Administrator
ControlWhat it does
Download templateDownloads a CSV with the right column headings and two filled-in example rows, using your own budget lines. Opens in Excel.
Columns (list)Every column the importer understands, which are required, and the format each expects.
Budget lines in use (list)Every active line with its direction. Names in the sheet must match these.
Spreadsheet (file picker)Accepts .xlsx and .csv, up to 2MB and 500 rows. Choosing a file immediately checks it — nothing is saved.
Preview tableOne row per line in your sheet: the row number as the spreadsheet counts it, the date, description, amount, and either Ready or the exact problems found.
CancelCloses and discards the upload.
Import N entriesOnly enabled when every row is ready. Writes them all as pending.
Import another sheetAfter a successful import, resets the dialog for the next batch.
Back to the ledgerCloses and refreshes the ledger behind it.

If any row has a problem, nothing is imported

Fix the rows the preview names and upload the file again. Imported entries are pending exactly like typed ones, and each one gets its own audit entry naming the file it came from.

08 Approvals

Everyone can see it · only auditors and administrators can act

Entries are listed oldest first. The line under the title says how many are waiting and by how much they would move the balance.

Each card shows the description and amount, then date · budget line · method · payee; who recorded it, how long ago, and the exact timestamp; the reference if there is one; and the note if there is one.

ElementWhen it appears
Open the receiptThe entry has a receipt link. Opens it in a new tab.
No receipt reference and no receipt linkAn expense with neither. It cannot be verified later.
Re-submitted after editIt was reviewed before and has changed since, so the earlier decision no longer applies.
Control What it does Who
ApproveApproves immediately. The balance moves by that amount from this moment.AUD ADM
RejectOpens the reason box.AUD ADM
Cancel / Reject entryBack out, or confirm. A reason is required — Reject entry stays disabled until you type one.AUD ADM

If you recorded the entry yourself, the buttons are replaced by "You recorded this one, so another reviewer has to clear it." Accountants and viewers see "An auditor reviews this one."

Empty queue: "Nothing waiting. The accountant is up to date." Voiding is not on this screen — open the entry from the Ledger to void it.

09 Audit trail

Auditor Administrator Viewer

Every logged action, newest first. Read-only, for everyone.

ControlWhat it does
PersonNarrows to one actor. Defaults to Anyone.
ActionCreated, Edited, Approved, Rejected, Voided, Closed month, Reopened month, Signed in.
From / ToThe date range.
Snapshot / HideExpands the full record as it stood immediately after that action, as raw data. Only on rows that carry one.
Previous / NextMove between pages.

Columns: When · Who · Action, with the kind of record beneath it · What changed.

The "What changed" column gives a plain sentence, and under it the field-level changes, one per line, as amount: 40,000 → 45,000. The new value is the darker of the two.

No filter combination reveals a way to edit or delete an entry, because none exists. Nothing matching: "No actions match these filters."

10 Exceptions

Auditor Administrator Viewer

Six checks over the book. An accountant who reaches this address sees a short note explaining that it is a reviewer's screen.

Each section is a collapsible panel. Sections with something in them open automatically; empty ones stay shut and read "Nothing flagged".

ControlWhat it does
Section headingClick to expand or collapse. The count sits beside the title, and the line under it explains why the check matters.
Show / HideThe same toggle, on the right of the heading.
Any entry descriptionLinks into the Ledger, filtered to that day and that description.
SectionWhat it catches
Missing receiptExpenses, pending or approved, with no reference and no receipt link.
Edited after reviewEntries changed after a review had already happened.
Large amountsAt or above the threshold set for this installation. The heading states the figure.
BackdatedRecorded more than seven days after the date on the entry.
Possible duplicatesEntries sharing a date, an amount and a budget line, grouped together.
Waiting too longPending for more than seven days.

Each list holds at most 100 rows. There is no date filter on this screen — it reads the whole book.

11 Reports

All roles · approved entries only

ControlWhat it does
From / ToThe range. Nothing changes until you press Show range.
Show rangeApplies the dates.
This month / Last month / This quarter / This yearOne-click ranges.

The five figures: Opening balance · Money in · Money out · Net · Closing balance. The closing balance is emphasised and carries the count of approved entries, plus anything still pending in that range.

Panel What it shows Its CSV exports
Spending by budget line Red bars, largest first, each with its share of total spending. Where the line has a monthly budget, the caption compares actual against budget for the range. Budget line, entries, amount, share %, budget for range
Income by budget line The same in green. Budget line, entries, amount, share %
Payment methods A table splitting each method by direction. Method, direction, entries, amount
Month by month A table of money in, money out and net per month. Month, entries, money in, money out, net

Every CSV button is disabled when its table is empty. All four panels count approved entries only, which is why report totals reconcile exactly with the ledger's closing balance for the same range.

12 Settings

Reachable from the sidebar by auditors and administrators, and from the Password link by anyone. What you see depends on your role.

Your account

Everyone
ControlWhat it does
Current passwordYour existing password.
New passwordAt least 8 characters.
Change passwordApplies it. You stay signed in; the new password works from the next sign-in.

Budget lines

Administrator only
ControlWhat it does
New lineThe name of the line to add.
KindExpense or Income. Decides which direction of entry can use it.
Monthly budgetOptional. Feeds the budget-against-actual comparison in Reports.
Add lineCreates it. Disabled until a name is typed.
Edit (per row)Turns the name and budget into editable boxes.

A line that any entry uses cannot be deleted; the system will tell you to deactivate it instead. Renaming is safe — the audit trail keeps the old name against the entries that used it.

People

Administrator only
ControlWhat it does
Name, Email, Role, First passwordThe new person's details. The line under the form describes what the chosen role can do.
Add personCreates the account. Hand the first password over in person.
Role (per row)Changes that person's role immediately. Disabled on your own row.
Reset passwordOpens a box for a new password, then Reset password confirms. Disabled under 8 characters.

The table also shows each person's email and when they last signed in. You cannot change your own role or deactivate yourself — that is what stops the last administrator locking everyone out.

Close a month

Auditor Administrator
ControlWhat it does
MonthThe month to close. Offers the last 12, marking any already closed.
Cash you countedWhat you physically counted. Leave empty if you are not reconciling cash.
NoteAnything worth recording about this close.
Close MarchThe button names the month. Closes it. Reads "March is already closed" and stays disabled if it is.
Reopen (per closed month)Reopens that month. Administrators only, and logged.

Before you confirm, four figures appear: Book balance (what the system says), Counted (what you say), Variance (counted minus book, green over, red under) and Still pending.

Closing is refused while anything in that month is pending, and the message tells you how many. The table underneath lists every closed month with its balance, count, variance, who closed it and when.

13 Where each rule is enforced

Buttons you cannot use are hidden, but hiding is a convenience, not the control. Every rule below is checked on the server when the request arrives, so it holds no matter how the request is made.

RuleEnforced
Auditors cannot record or edit entriesServer
Nobody approves their own entryServer
Accountants edit only their own pending entriesServer
Rejecting and voiding require a reasonServer
Editing a reviewed entry returns it to pendingServer
Nothing dated in a closed month can changeServer
A month with pending entries cannot be closedServer
The audit trail cannot be edited or deletedNo route exists to do it
You cannot demote or deactivate yourselfServer
